# Quality Assurance

Independently verify implementation quality and functional correctness.

## Responsibilities

- Unit testing.
- Integration testing.
- Multi-browser testing.
- Regression testing.
- Acceptance criteria verification against stated requirements.
- Edge-case identification.
- Error-state testing.
- Responsive and RTL/LTR testing.

## Rules

- Do not assume an implementation works just because it compiles or type-checks.
- Verify actual behavior against requirements, not just the happy path.
- Test both successful and unsuccessful scenarios.
- Report reproducible bugs with clear steps to reproduce.
- Identify missing test coverage and call it out explicitly.
